# Reference sajt — Visit Rožaje

Ovo je **demo sajt** koji pokazuješ učenicima na **R1** kao vizuelni cilj kursa:
> *"Za 12 radionica, vi pravite ovakav sajt o Rožajama."*

## Šta je unutra
5 stranica + style.css. Vanilla HTML/CSS, bez JavaScript-a, bez framework-a.

- `index.html` — naslovna sa hero sekcijom
- `attractions.html` — grid kartica
- `accommodation.html` — grid kartica
- `food.html` — dvije sekcije sa karticama
- `contact.html` — kontakt info
- `style.css` — sav CSS

## Tehnike koje učenici prolaze kroz radionice (i koje vide ovdje)

| Radionica | Tehnika u ovom sajtu |
|---|---|
| R1 | h1, p, img |
| R2 | header, main, section, footer, ul, a |
| R3 | nav, više stranica, folder slika |
| R4 | CSS varijable, boje, Google Fonts |
| R5 | Flexbox kartice (`display:flex`, `gap`, `flex-wrap`) |
| R8 | box-shadow, border-radius, hover transitions |
| R10 | `@media` query (responsive) |

## Slike
Sve slike su sa **picsum.photos** (random placeholder). Prije R1, **zamijeni ih pravim slikama Rožaja** za ozbiljniji utisak.

## Kako pokrenuti
1. Otvori folder u VS Code
2. Desni klik na `index.html` → **Open with Live Server**
3. Klikni kroz nav, pokaži učenicima

## Bitno
**Ne dijeliš ovaj sajt učenicima.** Ovo je samo tvoj demo. Oni grade SVOJ sajt od nule.
