## 🛠 Ako niste bili danas — kako da budete spremni

1. Instalirajte **VS Code** → https://code.visualstudio.com

2. U VS Code-u otvorite **Extensions** (`Ctrl+Shift+X`) → ukucajte "Live Server" (autor: Ritwick Dey) → Install

3. Na desktopu napravite ovakvu strukturu foldera (koristićemo za svaku radionicu):

   ```
   mzdpr_radionica/
     r1/
       class/        ← što radimo na času
       exercises/    ← vaše vježbanje kod kuće
       notes.md      ← bilješke sa časa
   ```

   Za svaku sljedeću radionicu pravićemo novi folder (`r2`, `r3`, ...) sa istom strukturom.

4. Otvorite `r1` folder u VS Code-u (File → Open Folder), pa u `class/` napravite fajl `index.html`, ukucajte `!` pa Tab — VS Code vam izbaci HTML skelet.

5. Desni klik na `index.html` → **"Open with Live Server"** — ako se otvori browser, sve radi ✅

Pitajte u grupi ako nešto zaglavi.
