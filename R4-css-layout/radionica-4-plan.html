Radionica 4 — CSS Layout (Flexbox)

Trajanje 2h  •  Tema: kako da rasporedimo elemente — kartice u redu, layout kao pravi sajt

Velika ideja danas: HTML = skelet, CSS (boje/fontovi) = namještaj, Layout = gdje šta stoji u sobi.

Do sada sve stoji jedno ispod drugog. Danas učimo Flexbox — kako da stvari stoje u redu, pored sebe.

1 · Obnavljanje gradiva sa Radionice 3 (0:00–0:15)

Brzo, kroz pitanja grupi — ne predavanje. Cilj: provjeriti da osnova iz prošlog časa leži.

  • "HTML kaže ŠTA, CSS kaže KAKO IZGLEDA" — neka neko ponovi.
  • Kako povezujemo CSS sa HTML-om? → <link rel="stylesheet" href="style.css"> u <head> svih stranica.
  • Razlika element selektor (h1) i class selektor (.title — sa tačkom).
  • Šta rade color, background-color, font-family, padding, margin.
  • Box model — svaki element je kutija: content → padding → border → margin. (Otvori DevTools F12, klikni element, pokaži dijagram — "nije magija".)
Provjera spremnosti: svi treba da imaju sajt iz R3 sa CSS-om (boje + font rade). Ko nema — neka sjedne pored nekog iz tima dok ne stigne.

2 · Demo "prije / poslije" (0:15–0:20)

  • Pokaži reference sajt → stranicu sa karticama (atrakcije).
  • Otvori Airbnb ili Booking → isti pattern: kartice u redu.
  • "Ovo se zove layout. Alat #1 za to je Flexbox. Danas učimo 4 propertyja koja pokrivaju 80% slučajeva."

3 · Mini-lekcija: Flexbox  TI KUCAŠ UŽIVO (0:20–0:45)

Kucaj polako, mijenjaj vrijednost → Save → Live Server refresh → "vidite razliku?" poslije svake linije.

TI KUCAŠ samo ova 4 propertyja na containeru (ne na karticama): 
.card-grid {
  display: flex;            /* aktivira Flexbox — slaže djecu u red */
  gap: 2rem;               /* razmak između kartica */
  justify-content: center; /* horizontalno poravnanje */
  flex-wrap: wrap;         /* prelama u novi red kad nema mjesta */
}

Demonstriraj svaki property uživo mijenjajući vrijednost:

  • display: flex → elementi se naredjaju u red (obriši ga → vrate se ispod).
  • gap → mijenjaj 1rem / 3rem, vidi razmak.
  • justify-content → center / flex-start / space-between — pokaži razlike.
  • flex-wrap: wrap → suzi prozor → kartice padaju ispod (bez ovog se stisnu).

4 · Vođena vježba — svi rade isto  ONI KUCAJU (0:45–1:00)

Svi otvaraju svoju attractions.html i kucaju isto što i ti — tako možeš debug-ovati jednu stvar za sve.

ONI KUCAJU u HTML (3 kartice): 
<section class="card-grid">
  <article class="card">
    <img src="images/hajla.jpg" alt="Hajla">
    <h3>Planina Hajla</h3>
    <p>Najviši vrh okoline Rožaja...</p>
  </article>
  <!-- još 2 kartice po istom šablonu -->
</section>
ONI KUCAJU u style.css: 
.card-grid {
  display: flex;
  gap: 2rem;
  flex-wrap: wrap;
  justify-content: center;
}
.card {
  flex: 1 1 280px;       /* "recept" — ne objašnjavamo detaljno danas */
  max-width: 350px;
  background: white;
  border-radius: 12px;
  overflow: hidden;
}
.card img {
  width: 100%;
  height: 200px;
  object-fit: cover;     /* slike iste visine, ne razvuče ih */
}
.card h3 { margin: 1rem 1rem 0; }
.card p  { padding: 0 1rem 1rem; color: #6c757d; }

Save → "OHOHOO". To je "wow" trenutak — kartice se prvi put naredjaju u red.

Najčešće greške (pripremi se na njih)

  • display: flex na pogrešnom elementu (na .card umjesto .card-grid) → ništa ne radi.
  • Bez flex-wrap: wrap → kartice se stisnu na malom ekranu.
  • Slike različitih dimenzija → kartice nisu iste visine → object-fit: cover + fiksna height.
  • Zaboravljen ; ili } — CSS prestaje da radi od te linije.
  • Promjena se ne vidi → nisu sačuvali (Save) ili Live Server ne radi.

Šta danas NE diramo

align-items, flex-direction, flex-grow/shrink, CSS Grid — vrati ih ako pitaju: "kasnije, prvo ovo savladajte."

Pripremi prije časa

  • DevTools mobile view spreman (pokaži kako kartice "wrap-uju").
  • Provjeri da svi imaju funkcionalan R3 sajt (boje + font rade).
  • Par slika Rožaja na USB-u za one koji nemaju (images/).
